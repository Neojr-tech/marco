# DUIX — FONTES OPEN-SOURCE

## Duix-Mobile
GitHub: https://github.com/duixcom/Duix-Mobile

Descrição da fonte: avatar digital interativo em tempo real, com implantação local/on-premise e baixa latência. É especialmente relevante para a parte de avatar interativo no celular.

## Duix-Avatar
GitHub: https://github.com/duixcom/Duix-Avatar

Descrição da fonte: toolkit open-source para avatar digital, clonagem de aparência/voz e síntese de vídeo offline. O projeto informa execução local em Windows e uso de texto/voz para conduzir o avatar.

## Pontos relevantes para o Chatbot Namorado Virtual
- Avatar digital como camada separada da inteligência conversacional.
- Possibilidade de processamento local/offline para componentes visuais.
- Voz e vídeo como módulos independentes.
- Referência para futura integração de avatar com o ai-gateway.
- Duix-Mobile é particularmente relevante para estudar a execução no dispositivo.

## Observação
Não copiar o repositório inteiro para o projeto. Usar como fonte técnica e verificar licença/compatibilidade antes de qualquer reutilização de código ou modelo.
