# REALCHAR — FONTE OPEN-SOURCE

Projeto: Shaunwei/RealChar
GitHub: https://github.com/Shaunwei/RealChar

## Por que esta fonte foi selecionada
Projeto open-source de personagem/companheiro de IA em tempo real. O README descreve criação e personalização de personagens, personalidade, background, voz, conversa por texto/voz e memória. Também possui componentes para web, terminal e aplicativo móvel.

## Pontos relevantes para o Chatbot Namorado Virtual
- Estrutura de personagem configurável.
- Personalidade e background configuráveis.
- Conversa em tempo real por texto e voz.
- Memória/contexto como componente do sistema.
- Arquitetura modular, permitindo trocar componentes.
- Referência para integração mobile/web.
