# LINLY-TALKER — FONTE OPEN-SOURCE

GitHub: https://github.com/Kedreamix/Linly-Talker
Stream: https://github.com/Kedreamix/Linly-Talker-Stream

## Por que esta fonte foi selecionada
Sistema de diálogo com humano digital que combina LLM, ASR, TTS, clonagem de voz e geração/animação de avatar. O projeto possui suporte a diálogo multi-turno e contextualizado.

A versão Stream é especialmente relevante para o conceito de conversa natural: o projeto informa arquitetura baseada em WebRTC, transmissão de áudio/vídeo de baixa latência, conversação full-duplex e interrupção (barge-in).

## Pontos relevantes para o Chatbot Namorado Virtual
- Conversação multimodal.
- Contexto de múltiplas mensagens.
- ASR + LLM + TTS + avatar.
- Voz/clonagem de voz como módulo separado.
- WebRTC para interação em tempo real.
- Barge-in/interrupção do avatar enquanto fala.
- Referência para futura camada de voz/vídeo do ai-gateway.

## Observação
Não copiar o código inteiro para o projeto. A finalidade aqui é preservar a fonte e os conceitos técnicos que poderão alimentar decisões futuras.
